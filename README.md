# Portfólio - Stefano Albertini

Site pessoal criado para praticar HTML e CSS durante meus estudos de programação. Apresenta quem eu sou, como comecei minha jornada e como entrar em contato.

## O que tem no site

* Tela inicial com título em destaque e arco de luz feito só com CSS
* Menu fixo no topo, com rolagem suave entre as seções
* Seção "Sobre mim" com foto
* Seção "Como comecei" com os passos da minha jornada
* Links de contato: e-mail, GitHub e WhatsApp
* Layout responsivo, que se adapta ao celular

## Tecnologias

* HTML5
* CSS3 (variáveis, flexbox, animações e media queries)
* Fonte Poppins, do Google Fonts

O projeto não usa JavaScript nem bibliotecas externas.

## Estrutura do projeto

```
portfolio/
├── index.html
├── style.css
└── img/
    ├── logo-sa.png
    ├── foto.png
    ├── email.svg
    ├── github.svg
    └── whatsapp.svg
```

## O que aprendi com este projeto

* Estruturar uma página com HTML semântico (`header`, `main`, `section`, `footer`)
* Organizar o CSS com variáveis para manter as cores num lugar só
* Centralizar e alinhar elementos com flexbox
* Posicionar elementos com `position` (`absolute`, `relative` e `fixed`)
* Criar layouts responsivos com `@media`
